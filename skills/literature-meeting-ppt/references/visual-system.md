# 组会 PPT 视觉系统

除非用户提供了现成模板，否则默认使用下面这套“中文组会蓝灰学术主题”。同一份 PPT 内不得临时更换颜色、字体、圆角、页边距或页脚样式。

## 主题令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F7F8FA` | 普通页面背景 |
| `ink` | `#111827` | 标题、正文、核心结论 |
| `muted` | `#5B6472` | 副标题、注释、来源 |
| `blue` | `#0B5FFF` | 主强调、研究主线、第一层级 |
| `blueSoft` | `#DCE8FF` | 主强调浅底 |
| `teal` | `#009E9A` | 第二模块、数据或语义分支 |
| `orange` | `#E88A24` | 挑战、警示、第三模块 |
| `purple` | `#6B4EFF` | 仅用于第三类对比或研究想法 |
| `panel` | `#EEF2F7` | 信息卡片、解释面板 |
| `line` | `#D8DEE8` | 分隔线、表格线 |
| `white` | `#FFFFFF` | 封面文字、图像承载底 |
| `dark` | `#0B1220` | 封面与结尾页底色 |

颜色角色固定：蓝色代表主线/检测器，青色代表数据或语义，橙色代表挑战/效率/风险，紫色只用于研究方向。不要为单个页面新增近似颜色。

## 画布与字号

- 默认画布为 16:9，`1280 × 720`；用户已有模板时先读取模板尺寸并保持不变。
- 默认安全边距为 `72 px`；标题、正文、图和页脚不得贴边。
- 页眉固定：kicker 位于 `y=34`，标题位于 `y=72`，分隔线位于 `y=148`。
- 页脚固定：分隔线位于 `y=672`，来源位于 `y=682`，页码右对齐。
- 默认字体使用 `Microsoft YaHei`；英文模型名、论文标题和公式可保留原字体，但同一类文本必须统一。
- 封面标题至少 50 pt，普通页标题 40–46 pt，副标题 22–26 pt，正文 20–24 pt，卡片标签 16–20 pt，来源 12–14 pt。
- 普通页面标题最多两行；正文单个文本块最多 4 行；一页正文 bullet 默认不超过 4 条。

## 固定组件

用 `artifact-tool` 或等价演示文稿工具实现并复用以下组件，不要在每页手写一套新样式：

- `addHeader(kicker, title, page)`：统一页眉、标题、分隔线和页码。
- `addFooter(source, page)`：统一来源、分隔线和页码。
- `addPaperFigure(bytes, x, y, w, h, alt)`：论文原图统一使用 `contain`，白色承载底，不拉伸变形。
- `addMetric(value, label, ...)`：统一数字强调样式，数字用主题色，标签用 `muted`。
- `addBullet(text, ...)`：圆点颜色只从主题令牌中选择，正文保持 `ink`。
- `addPill(text, ...)`：只用于 Paper、Code、DVC、VisGT 等短标签，不用于长句。

如果工具支持主题对象，先定义一个不可变的 `DECK_STYLE`，集中保存上述颜色、字号、边距和组件参数；生成所有页面前先锁定它。不要在页面代码中出现未登记的颜色值或随机字号。

## 页面类型与版式槽位

每页先选择一种页面类型，再套用对应槽位；不要从上一页复制后随意挪动元素。

| 页面类型 | 推荐结构 | 图文比例 |
| --- | --- | --- |
| `cover` | 左侧主题、论文范围、日期；全幅遥感背景加深色遮罩 | 视觉 70% / 文字 30% |
| `landscape` | 左侧研究问题，右侧趋势/路线时间线 | 视觉 40% / 文字 60% |
| `challenge` | 上方结论句，中部 2–3 个挑战卡片，下方一句判断 | 视觉 40% / 文字 60% |
| `paper-intro` | 论文标题与作者信息，上半区动机，下半区挑战 | 视觉 30–40% / 文字 60–70% |
| `method` | 左侧或中央放原论文主图，右侧/下方放 1–3 条中文讲图要点 | 图 60–70% / 文字 30–40% |
| `evidence` | 左侧指标或结论，右侧原始定性图/表，标注数据来源 | 图 50–60% / 文字 40–50% |
| `comparison` | 固定列宽的对比表，底部一条共同趋势结论 | 结构 60% / 文字 40% |
| `gap-idea` | 左侧 Gap，中央箭头，右侧 Idea；只保留三层证据 | 视觉 45% / 文字 55% |
| `takeaway` | 深色底、左侧三条 Key Takeaway、右侧讨论问题 | 视觉 30% / 文字 70% |

方法页优先使用约 `60–70%` 的图槽位；原图过宽时裁掉论文页眉、页码和图注，只保留 Figure 本体，并在 PPT 页脚/备注写明图号和来源。原图过高时按比例缩放，不压扁、不拉伸、不覆盖关键模块。

## 一致性验收

- 生成前记录：画布尺寸、主题令牌、字体、页眉页脚坐标、页面类型和原图处理策略。
- 生成中检查：所有页面只使用 `DECK_STYLE`；相同信息使用相同组件；论文标题、模型名、Dataset、Venue 不改写。
- 生成后必须渲染整套 PPT，查看 montage 和所有方法页；检查标题行数、图像清晰度、图文比例、页脚来源、页码、文本溢出和元素重叠。
- 使用演示文稿测试工具运行 overflow / overlap 检查；失败时先修复版式，再交付。
- 若用户没有明确要求换主题，后续改稿只修改内容和图，不改变主题令牌、组件、字号层级和页面网格。
