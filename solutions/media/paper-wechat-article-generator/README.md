# 论文 PDF 生成公众号文章

这是一个下载后由本地 AI Agent 执行的 Skill 方案。云端解决方案中心只提供说明、演示位置和方案包下载，不读取论文 PDF，也不生成文章。

## 使用

1. 下载并解压完整方案包。
2. 使用 Codex 打开 `paper-wechat-article-generator/` 文件夹。
3. 附上论文 PDF，发送：

   ```text
   请阅读当前目录中的 SKILL.md，把我提供的论文 PDF 写成中文公众号解读文章，并把 article.md、paper.pdf 和 pics/ 保存到指定输出目录。
   ```

方案包根目录中的 `SKILL.md` 是 Agent 执行规范。站内也保留了单独下载 Skill 的入口，适合已经熟悉安装方式的用户。
